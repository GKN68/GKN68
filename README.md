# Ginam Kim

Mechanical Engineering undergraduate at KAIST. I build simulation and data tools for race cars.

My main project is **PicoSim**, a vehicle dynamics simulator for Formula Student cars. The goal is a simulator that
calibrates itself from real driving data and then helps design the car: battery size, power, vehicle size and
suspension kinematics.

**Portfolio:** [gkn68.github.io](https://gkn68.github.io)

## Projects

| Project | What it is |
|---|---|
| [PicoSim](https://gkn68.github.io/simulator.html) | Real-time vehicle simulator: 1 kHz physics, Pacejka MF 6.1 tires, force-feedback steering, automated test runs and telemetry export. |
| [PicoSim Telemetry](https://github.com/GKN68/picosim-telemetry) | ESP32 data logger and a browser-based analysis tool with 52 predefined engineering graphs. Opens car logs and simulator logs side by side. [Try the demo](https://gkn68.github.io/app/telemetry.html?demo=1). |
| [PicoSim Autonomous](https://gkn68.github.io/autonomy.html) | Camera and LiDAR cone perception, EKF-SLAM, racing-line planning and MPC, tested in PicoSim. |
